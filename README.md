# Student Performance Analyzer

A beginner-friendly Python project designed to analyze student academic performance, calculate grades, classify students, generate rankings, and export results to a CSV file.

This project was developed as part of my learning journey in Computer Science, with a focus on practicing Python fundamentals and data manipulation.

## Features

- **Average Calculation:** Calculates the average grade of each student.
- **Student Classification:** Classifies students as Passed or Failed based on a minimum average of 7.0.
- **Class Statistics:** Calculates the total number of passed and failed students and the overall class average.
- **Performance Analysis:** Identifies the students with the highest and lowest averages.
- **Ranking System:** Generates a ranking of students based on their academic performance.
- **CSV Export:** Exports student information and results to a CSV file, with averages formatted to two decimal places.

## How to Run

1. Clone this repository:

```bash
git clone https://github.com/jpauloxvr/Student-Performance-Analyzer.git
```

2. Navigate to the project directory:

```bash
cd student-performance-analyzer
```

3. Run the program:

```bash
python main.py
```

On Windows, you can also use:

```bash
py main.py
```

4. The program will display the analysis results in the terminal and generate a CSV file containing the processed student data.
